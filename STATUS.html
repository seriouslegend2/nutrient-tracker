Current Limitations

  • Search is normalized substring matching, not ranked or semantic retrieval.
  • The optional dish seed contains 61 curated rows; the database migration contains 18 category defaults. There is no demo account seed.
  • Raw upload bytes are not persisted, so media replay and later visual admin inspection are unavailable.
  • Image/audio/PDF byte limits exist; PDF page and audio-duration limits do not.
  • Nutrition-label routing requires an explicit text or filename hint.
  • The customer manifest has no service worker/offline implementation. Export, self-service deletion, and a general post-onboarding profile editor are absent.
  • The dashboard intentionally omits user search/filter/sort, Food DB administration, body history, goal progress, and audit panels.
  • Frontend API interfaces are handwritten. There is no generated shared type/client artifact.
  • Focused Vitest suites cover email/password routes, safe redirects, backend JWT generation, API clients, pagination, and dashboard panel contracts: 27 customer auth tests and 22 dashboard tests. The real hosted Playwright suite passed all 14 non-agent scenarios with PDF evidence.
